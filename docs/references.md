## Notes for the team

- **Check every link before submission.** AWS documentation URLs change, and a
  broken link in a reference list is easy for an assessor to spot.
- **Update the viewed date** when you re-check a source.
- **Use the lettered suffixes** (`2026a`, `2026b`) when citing several sources by
  the same author in the same year, and cite them that way in the text.
- Unit materials are cited as CQUniversity with the year, as above.
